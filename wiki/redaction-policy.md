# Redaction Policy

이 위키에서 공개하는 정보와 공개하지 않는 정보의 기준을 명시한다.

## 공개하는 것

- 이름, 연락처, GitHub/velog 프로필 (이미 공개)
- 재직 회사명 (파이랩테크놀로지, 스마트마인드) — 공개 정보
- 직무, 직책, 재직 기간
- 기술 스택 (TypeScript, React, Next.js 등)
- 업적 설명 — 구현한 기능, 개선 방향, 기술적 판단
- 측정 수치 — 로컬 Lighthouse 수치 (이미 공개 이력서에 기재됨), aggregate PR 통계
- 자체 증언 (self-attested) 사업 지표 — 이미 공개 이력서에 기재된 것에 한함
- 공개 velog 글 링크 (https://velog.io/@ss-won)
- 파트너 제품명 — 이미 공개 이력서에 명시된 것에 한함 (Hashport Wallet 등)

## 공개하지 않는 것

| 항목 | 이유 |
|---|---|
| 사내 GitHub 저장소 링크 (github.com/bifrost-platform/*) | 비공개 저장소 — 외부 접근 불가 |
| 사내 PR 번호·직접 링크 | 비공개 저장소 내부 링크 |
| 팀 구성원 이름, 팀 규모 | 조직 내부 정보 |
| 내부 Jira URL, 내부 API endpoint | 내부 시스템 |
| 사내 도구명 (예: 내부 AI Agent 이름) | 공개 확인 전 보류 |
| 고객사 이름 (이미 공개 이력서에 없는 것) | 고객 정보 보호 |
| 매출·TVL·실사용자 수 (공개 이력서에 없는 것) | 회사 기밀 사업 지표 |
| 코드 발췌·사내 알고리즘 | 영업 비밀 가능성 |
| `.env`, credentials, private key 등 | 보안 |

## 증거 레벨 정의

| 레벨 | 의미 |
|---|---|
| **Public** | 공개 이력서, velog, GitHub public 저장소에서 직접 확인 가능 |
| **Redacted-internal** | 비공개 GitHub 데이터로 확인됨; 근거는 있으나 링크는 비공개 |
| **Self-attested** | 엔지니어 본인이 제공한 사업 지표; 외부 독립 검증 불가 |
| **Derived** | 공개 데이터에서 계산된 값 (예: merge rate = merged/authored × 100) |

## 면접 활용 원칙

- 이 위키에 기재된 내용은 면접에서 질문을 받을 때 상세히 설명할 수 있는 것만 포함한다.
- 비공개 저장소 링크를 면접관에게 제공하지 않는다 (접근 불가).
- 사업 지표는 self-attested임을 인지하고, "팀에서 공유된 수치 기준으로는…" 형태로 답변한다.

## 갱신 시 확인 사항

새 내용을 추가하기 전:
1. 비공개 저장소 링크가 포함되는지 확인
2. 새로운 사업 지표가 이미 공개된 이력서에 있는지 확인
3. 파트너·고객 이름이 공개 이력서에 이미 명시됐는지 확인
4. 코드 발췌가 포함되는지 확인

의심스러우면 "Self-attested, 면접에서 확인 필요"로 표시하고 게시를 보류한다.
